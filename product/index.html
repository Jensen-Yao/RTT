RTT TRANSLATOR

文件不是一段更长的文字。

RTT 会先判断文件类型和当前翻译路线：本机提取 PDF 文本层，扫描 PDF 在 Android 使用设备端 OCR；SRT/VTT 保留序号和时间码；DOCX、PPTX、XLSX 只有在所选服务声明支持原生文档翻译时才上传并返回保留版式的文件。

进入翻译机

PDF 与扫描件

Web/Windows 提取文本层；Android 可逐页 OCR。无可读文本时会明确提示切换 OCR 或原生文档服务。

Office 与版式

DeepL 等原生文档接口走上传、状态轮询、结果下载流程；普通文字模型不会被误报为可保留版式。

字幕与结构化文件

SRT、VTT 保留时间轴；同时接受 TXT、Markdown、HTML、JSON、XML 与 XLIFF。

任务与结果

显示分析、提取、OCR、翻译和重建进度；完成后可预览文本或下载二进制结果。

开始之前，只要选好输入方式

RTT 不播放视频，也不修改原视频。它在视频或聊天应用上方显示独立字幕层。

2

开始翻译

首次授予录音、悬浮窗和屏幕捕获权限；画面字幕需先框选字幕区域。

适合三种常见场景

语音和画面能力彼此独立，可以按场景组合，避免为了一个功能配置整套服务。

视频与直播

捕获允许录制的应用音频，实时显示原文和简体中文字幕。

语音聊天与会议

使用麦克风识别扬声器播放的远端声音，适合外放场景。受保护的通话音频无法直接内录。

已有原文字幕的视频

框选屏幕中的字幕区域，设备端 OCR 稳定识别后再翻译；也可与语音同时运行。

从“能用”开始，再按需要换模型

应用内保留模型下载和自主选择入口。安装包已包含基础离线能力，其余模型只在用户主动选择后下载。

Vosk 小模型

速度优先。英语、日语及更多单语言模型可按需下载；适合资源有限的设备。

SenseVoiceSmall INT8

本地多语识别的默认准确模式，适合英语、中文、日语、韩语和粤语。

Omnilingual CTC 300M INT8

面向广语言覆盖。新版启动路径已修正，无需重新下载模型；没有标点模型时 RTT 会使用语言规则分句。

Qwen3-ASR 0.6B INT8

可选高准确率模型，约 879 MB，适合大内存 Android 设备和 Windows。

本地与专用翻译

ML Kit 语言包、已验证的 Marian ONNX 包、DeepL、百度翻译、LibreTranslate 都可作为文字翻译路线。

前往发布页

你的内容，默认留在设备上

RTT 不收集遥测；诊断日志默认关闭，且不写入音频、字幕正文或 API Key。本地模式不会上传内容。云端模式会明确显示正在使用的能力、模型和提供方。

使用前请知道

  • DRM 保护、禁止 AudioPlaybackCapture 的应用和 FLAG_SECURE 画面无法绕过。
  • Android 的受保护通话音频无法直接内录。使用语音聊天时，请使用麦克风加扬声器。
  • 中文配音是低延迟译文播报，不是与口型同步的电影配音轨。
  • 模型越大通常越准确，但会占用更多存储、内存和电量。
