实时字幕

选择麦克风、标签页/系统音频或屏幕字幕区域，再组合 ASR、标点、翻译和 TTS 路线。Web 无法跨应用置顶时请安装 Windows 端。

打开 Web 字幕

专业翻译机

文本可直接双栏翻译；文档、字幕、图片和视频进入任务队列。视频可产出 SRT、VTT、ASS 或 TXT，并选择纯译文或双语。完成后可预览和下载。

打开翻译器

模型中心

先核对平台验证状态、运行时、许可证、大小和 SHA-256，再下载或导入。只有真实推理通过的组合才显示为 VERIFIED。

连接与 API

通用模型 API、专用翻译 API、ASR、OCR、TTS 和本地服务分别配置。DeepSeek 等文字模型必须与 ASR 路线组合。

配置连接

账户与隐私

RTT 不采集遥测。模型路径、音频、字幕和译文正文不进入账户同步；视频画面不上传，云端 ASR 只在确认后接收音轨。管理员查看云端密钥明文必须重新认证并记录原因。
